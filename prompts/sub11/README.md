# Sub_11 재제작 분할안 (11-21)

GMC-01(34.9초) 뒤를 잇는 46초. 개화 시트 4단계(빈 줄기 → 봉오리 → 반개 → 만개) × 꽃 6종을 크롭해 클립별 레퍼런스로 쓴다.

| 클립 | 길이 | 블록아웃 / 노션 | 내용 | 레퍼런스 |
| --- | --- | --- | --- | --- |
| S1 | 6s | B05 / C008 | GMC-01 마지막 줄기에서 이어 수관으로 상승, 동백 봉오리 → 개화 | GMC-01_last, camellia_s2, camellia_s4 |
| S2 | 8s | B06 / C009-C010 | 측면 → 탑뷰, 빛 응집, 섬광, 붉은 너울 만다라 | camellia_s4 |
| S3 | 7s | B07-B09 / C011 | 지면 매크로 2 + 측면 트래킹 2 + 나무 A 틸트업 3, 마지막에 금잔화 금색 | camellia_s3, marigold_s4 |
| S4 | 10s | B10 / C012 | 정면축 고정. 개화 전 정원(K4)에서 수국 → 제비꽃 → 진달래 → 수레국화 순 개화, 끝은 마지막 컷 시작 프레임 | K4_bare_garden, start_frame_empty_garden, azalea_s3, hydrangea_s3 |
| S5 | 15s | B11 / C013-C014 | 마지막 컷(기존 final-cut 프롬프트) | final-cut 폴더 |

합계 46초. GMC-01 34.9 + 46 = 80.9초.

판단과 근거
- S4를 노션 C012의 크레인(물러나며 상승) 대신 정면축 고정으로 바꿨다. 끝 프레임을 마지막 컷 시작 프레임과 같게 두면 S4 → S5가 컷 없이 이어진다. 크레인을 지키려면 S4 끝과 S5 사이에 하드컷이 생긴다.
- bloom 영상(GMC-bloom-flower.mp4)은 영상 레퍼런스로 넣지 않는다. 3x2 표 구도가 카메라와 배치를 끌고 간다(참고사항 "구도가 있는 레퍼런스"). 대신 그 생성 프롬프트의 개화 순서 문장을 S4에 재사용했다(bloom_video_prompt_found.txt).
- 크롭은 배경·구도를 따라오지 않게 역할 문장에서 "모양만" 쓰도록 제한했다.
- 줄기 재질은 GMC-01(매끈한 은회색 + 흰 점)을 따른다. 시트의 와이어 점선 줄기와 다르므로 S1에서 줄기 재질은 @image1에서만 가져오게 적었다.

미확인
- Seedance 6·7·8·10·15초 길이 지정 가능 여부. 13초만 확인됨.
- 영상 생성은 ts 계정에 무제한이 없어 크레딧이 든다. 프롬프트와 프레임까지만 준비.
