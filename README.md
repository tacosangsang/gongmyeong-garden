# 공명정원

전시 로비 소개용 AI 하이브리드 영상. 블록아웃(언리얼/블렌더) 81초 영상을 기준으로 생성형 AI로 화면을 올린다.

## 구조

```
gongmyeong-garden/
├── workflow/      # 작업 규칙, 프롬프트 구조, 도구 제약, 실패 사례
├── prompts/       # 클립별 프롬프트 (위에서부터 [최신])
├── 00 resources/  # 미디어 자리 표시 (실제 파일은 Drive)
└── 01 docs/       # 기획 문서 (바이너리는 Drive)
```

## 정본

- 스토리보드·스타일 규칙: Notion "공명의숲 | 로비 루프 스토리보드 · 연출 마감안"
- 블록아웃 영상: Drive `공명정원/공명정원-1차.mp4`
- 프롬프트 구조·검수 규칙: 이 저장소 `workflow/`
- 셋이 다르면 Notion이 맞다.

## 미디어

이미지·영상·바이너리는 GitHub에 올리지 않고 Drive "공명정원" 폴더에 둔다(`.gitignore`). 폴더 구조는 `00 resources/`와 같게 유지.
