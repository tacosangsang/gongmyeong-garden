# 07. 도구·환경 제약

| 도구 | 제약 | 우회 |
| --- | --- | --- |
| Google Drive 커넥터 | 10MB 넘는 파일을 못 받음 | 사용자 PC `G:\내 드라이브\공명정원`에서 직접 가져옴 |
| Higgsfield API/MCP | Seedream 5.5 무제한 모드 거절(11-20) | 웹 higgsfield.ai 이미지 페이지에서 무제한 토글로 생성 |
| ChatGPT Higgsfield 플러그인 | "Seedream 5.5 not available"(11-20) | 같음 |
| Higgsfield 웹 + 브라우저 자동화 | 참조 이미지 업로드 버튼 대신 붙여넣기 필요 | 프롬프트 칸에 paste 이벤트로 이미지 첨부 |
| Seedance | 9초, 15초 지원 여부 미확인 | 생성 직전 화면에서 확인 후 날짜와 함께 기록 |
